# Přibalené závislosti prohlížeče

PhotoSwipe 5.4.4, autor Dmitry Semenov, MIT.

Zdroj: https://github.com/dimsemenov/PhotoSwipe/tree/v5.4.4
Dokumentace: https://photoswipe.com/

Přibalené soubory byly získány z balíčku `photoswipe@5.4.4`:

- `dist/photoswipe.esm.js`
- `dist/photoswipe-lightbox.esm.js`
- `dist/photoswipe.css`
- `LICENSE` → `PHOTOSWIPE-LICENSE.txt`

Při sestavení se kopírují do obou výstupů. Web za běhu nepotřebuje npm ani CDN. Aktualizace je vědomá výměna těchto čtyř souborů a opakování testů lightboxu.
